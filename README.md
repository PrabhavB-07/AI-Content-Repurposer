# 🚀 AI Content Repurposer

Turn any Topic or YouTube Video into ready-to-publish content for multiple platforms using AI.

## 📌 Overview

AI Content Repurposer is a Flask-based web application that helps creators, marketers, freelancers, and businesses convert a single idea into multiple content formats instantly.

Simply enter a topic or a YouTube video URL, and the application generates:

* Instagram Post
* LinkedIn Post
* Twitter/X Thread
* Blog Post

The tool uses Groq AI for fast content generation and automatically extracts transcripts from YouTube videos.

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/yourusername/AI-Content-Repurposer.git
```

### Enter Project Folder

```bash
cd AI-Content-Repurposer
```

### Install Dependencies

```bash
pip install -r requirements.txt
```

### Add Environment Variables

Create a `.env` file:

```env
GROQ_API_KEY=YOUR_GROQ_API_KEY
```

### Run Application

```bash
python app.py
```

Open:

```text
http://127.0.0.1:5000
```
